# Data Sources, Access Methods & Licences (`data/`)

*Owner: Data + Dashboard (P2) | Updated for H1–H3*

## 1. Primary Data Sources

| Dataset | Source | Access Method | Licence / Terms |
| --- | --- | --- | --- |
| **Delhi Hourly Load** | Delhi SLDC (`delhisldc.org`) / Grid-India (POSOCO) daily/hourly reports, or public Kaggle/GitHub Delhi electricity load archive | Download CSV and pass via `python data/build_dataset.py --load-csv <path>` | Public Indian grid operational reports / dataset-specific Kaggle open licence |
| **Delhi Hourly Weather** | Open-Meteo Historical Weather API (`https://archive-api.open-meteo.com/v1/archive`) | Free REST API, no key required (`lat=28.6139, lon=77.2090, timezone=Asia/Kolkata`), pass `--fetch-open-meteo` | **CC-BY 4.0** (attribution to Open-Meteo / ERA5 reanalysis) |
| **Delhi Calendar & Events** | Public Government of NCT of Delhi gazetted holiday lists, lunar festival calendars, COVID-19 lockdown notifications (2020–21), Odd-Even notifications (2019) | Hand-curated deterministic lookup table inside `data/build_dataset.py` (`build_delhi_calendar`) | Public domain / factual dates |

## 2. Weather Proxy Note
Open-Meteo's Historical Archive API provides ERA5 reanalysis / historical weather observations rather than archived day-ahead NWP weather forecasts. Unless an archived weather forecast feed is supplied via `--weather-csv`, historical actual weather acts as a proxy at forecast time—this must be stated transparently in `docs/model_card.md`.

## 3. Clearly-Labelled Fallback Mode
If raw hourly Delhi load (`--load-csv`) or live Open-Meteo connectivity is unavailable before H1/H3:
- `data/build_dataset.py` generates a **clearly-labelled synthetic Delhi fallback** (`2020-01-01` to `2024-12-31`, `43,848` IST hours) matching Delhi's seasonal range (~2,000 MW winter to ~8,300 MW summer), cooling-degree sensitivity above 25 °C, 72h thermal inertia, festival/lockdown drops, and injected telemetry gaps/outages to exercise the cleaning pipeline.
- **Note to pass to Lead for `docs/model_card.md`** if fallback is used in final run:
  > *"Fallback synthetic Delhi hourly load/weather generated by `data/build_dataset.py` was used because local SLDC/Kaggle raw hourly CSV or live Open-Meteo API access was unavailable at run time. All structural assumptions (2,000–8,300 MW swing, CDH base 25 °C, lockdown/festival impacts) are synthetic proxies."*
